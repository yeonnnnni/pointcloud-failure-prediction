**오래 걸리거나 중단되면** 완료한 조건 수, 마지막 로그, 남은 작업, ETA, 재개 명령을 남긴다. 작업을 실행 중이라면 세션명이나 작업 ID, 로그 위치도 기록한다. 파일럿이나 미완료 조건의 결과에는 사용한 실제 범위를 표시한다. 환경·다운로드·체크포인트·데이터 매핑 문제가 풀리지 않으면 실패한 명령, 오류와 재개 조건을 기록하고 진행 가능한 작업을 먼저 마친다.
